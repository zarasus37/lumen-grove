## 1. What you get

The complete, working source of **Lumen Grove** — a mobile arcade-defense
hybrid built with Phaser 3, TypeScript and Vite — including:

| Included | What it is |
| --- | --- |
| `src/` | The whole game: simulation, renderer, UI, procedural art, synthesised audio |
| `tools/` | The balance & playtest harness (see `docs/HARNESS.md`) |
| `docs/` | The design synthesis map, this license, and the customisation guide |
| `public/` | The PWA manifest, service worker and app icons |
| A live, hosted demo | A URL you can send to buyers and reviewers |

There are **no image assets and no audio assets**. Every sprite is drawn
procedurally in code and every sound is synthesised at runtime in WebAudio, so
there is nothing to license, nothing to attribute and no asset pipeline to
build. The whole game is ~356 KB gzipped.
